# Passing-Network-FYP-
## Introduction
This project focuses on the analysis of passing networks in soccer matches, to determine if there is a correlation
between the efficiency of a certain passing network and the overall result of a match. This was conducted through
the use of network and data analysis, of which was developed using python, highlighting and comparing results extracted.

## Summary
This github repository contains code required to extract analytical data needed to conduct network & data analysis,
it also contains png files of passing networks produced along with visual representations of data extracted.
